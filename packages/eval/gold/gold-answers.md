# Gold Answers

The locked benchmark artifact is stored in `gold-answers.json`. This markdown companion records that the JSON was derived from the user-provided Q1-Q5 gold answers in the build prompt and must not be replaced with invented benchmark claims.

Smart punctuation in the locked JSON is stored with JSON Unicode escapes, such as `\u2019`, so Windows text tools, parser round-trips, and UI fixtures do not depend on console code page behavior.
